# Support

Use [GitHub Issues](https://github.com/JacksCodeVault/ros-plugin/issues) for reproducible bugs, feature requests, and usage questions. Choose the relevant template and search existing issues first.

Start with the [README](README.md) for installation and configuration and the [development guide](docs/DEVELOPMENT.md) when working from source.

Include the plugin version, UISP version, RouterOS version, PHP version if known, provisioning mode, expected result, actual result, and redacted error text. State whether the UISP host can reach the router's API address and port. Screenshots must hide subscriber identities, credentials, and private network details.

For vulnerabilities, use the private address in [SECURITY.md](SECURITY.md). For conduct concerns, follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

This is a community-maintained project. Support is best effort; no response time, uptime guarantee, or commercial support agreement is implied. Do not grant public access to your router or production UISP instance to obtain support.
